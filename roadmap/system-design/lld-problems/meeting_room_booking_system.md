
# Meeting Room Booking System

## Problem Statement

We have recently opened a new office in Pune and the new office has only a limited number of meeting rooms available.  
It is spread across floors and people are finding it difficult to search for a free meeting room across floors.

To solve this problem, we want to build a system that could let employees book a meeting room for a time period on a particular day.

---

## Functional Expectations

### 1. View Available Rooms

An employee should be able to:

- View the list of **free meeting rooms**
- For a **given time range**

---

### 2. Book a Meeting Room

An employee should be able to:

- Book a **meeting room**
- For a **given time range**
- On a **given day**
- **Only if the room is free**

---

### 3. View Booking Calendar

An employee should be able to view the **booking calendar** of a particular room:

- **Daily view**
- **Weekly view**
- **Monthly view**

The booking calendar should display:

- **Booked person**
- **Time range**
- **Meeting agenda**
